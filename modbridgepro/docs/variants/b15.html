ModBridge Pro B15

Firmware version

v5.0.0

Status

Current production variant

This is the baseline variant. All top-level documentation pages describe this variant in full.

Feature set

  • Modbus RTU (RS-485) and Modbus TCP, with contiguous registers merged into single block reads

  • Wi-Fi + Ethernet dual connectivity

  • MQTT publishing with store-and-forward buffering

  • Google Sheets publishing, tabular or JSON, with managed headers and automatic row trimming

  • Per-register error reporting in every published payload

  • Bundled Over-the-Air firmware updates, configuration preserved

  • Encrypted credential storage

  • Web-based configuration UI

Known limitations

  • Maximum 5 Modbus slave devices.

  • Maximum 50 registers per slave.

  • Read-only: the gateway polls registers and never writes to a field device.

  • MQTT publishes at QoS 0; the QoS setting selects the broker retain flag instead (see IoT Publishing Guide).

  • MQTT TLS/SSL cannot connect — no CA trust store is provisioned, and TLS is unsupported over Ethernet (see Security).

  • Custom TLS certificates are not uploadable via the web UI.

  • The buffer is in RAM, so buffered data does not survive a reboot or power cut.

  • Google Sheets writes to a tab named Sheet1 only.

  • Timestamps are fixed to IST (UTC +5:30).

Revision history

Version

Changes

v5.0.0

Store-and-forward buffering on every publish path; per-register error codes in MQTT and Google Sheets output; block reads that merge neighbouring registers into one request; Google Sheets header management and column-aware row trimming; configuration preserved across bundled OTA updates; USB recovery procedure documented.

v2.2.1

Stronger credential encryption; Google Sheets tabular/JSON output format selection; improved OTA update reliability.

v2.1.x

Encrypted IoT credential storage; password visibility toggle.

v2.0.x

Initial release — Wi-Fi + Ethernet dual connectivity; offline buffering; MQTT QoS 0/1/2 support.
