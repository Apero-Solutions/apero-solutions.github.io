=========================
ModBridge Pro B15
=========================

.. list-table::
   :widths: 30 70
   :header-rows: 0

   * - **Firmware version**
     - |release|
   * - **Status**
     - Current production variant

This is the baseline variant.  All top-level documentation pages describe
this variant in full.

Feature set
-----------

* Modbus RTU (RS-485) and Modbus TCP, with contiguous registers merged into
  single block reads
* Wi-Fi + Ethernet dual connectivity
* MQTT publishing with store-and-forward buffering
* Google Sheets publishing, tabular or JSON, with managed headers and
  automatic row trimming
* Per-register error reporting in every published payload
* Bundled Over-the-Air firmware updates, configuration preserved
* Encrypted credential storage
* Web-based configuration UI

Known limitations
-----------------

* Maximum 5 Modbus slave devices.
* Maximum 50 registers per slave.
* Read-only: the gateway polls registers and never writes to a field device.
* MQTT publishes at QoS 0; the QoS setting selects the broker retain flag
  instead (see :ref:`iot`).
* MQTT TLS/SSL cannot connect — no CA trust store is provisioned, and TLS is
  unsupported over Ethernet (see :ref:`security`).
* Custom TLS certificates are not uploadable via the web UI.
* The buffer is in RAM, so buffered data does not survive a reboot or power
  cut.
* Google Sheets writes to a tab named ``Sheet1`` only.
* Timestamps are fixed to IST (UTC +5:30).
