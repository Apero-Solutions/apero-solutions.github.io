Connectors and Peripherals
===========================

Wi-Fi
-----

Built-in 2.4 GHz antenna — no external antenna required.  Place the
ModBridge Pro B15 away from large metal enclosures to avoid signal
interference.

Ethernet Port
-------------

A wired Ethernet port that serves one of two roles depending on
configuration:

* **Internet uplink** — alternative to Wi-Fi when a wired connection is
  preferred.
* **Modbus TCP transport** — dedicated network for communicating with a
  Modbus TCP server (e.g., a PLC).  In this mode the port is not used for
  internet traffic.

RS-485 Terminal Block
---------------------

A 3-pin screw terminal for connecting Modbus RTU devices over RS-485 cable:

.. list-table::
   :widths: 20 80
   :header-rows: 1

   * - Pin label
     - Description
   * - **A (D+)**
     - RS-485 non-inverting data line
   * - **B (D−)**
     - RS-485 inverting data line
   * - **GND**
     - Signal ground — connect to Modbus bus ground

Use twisted-pair cable (e.g., CAT5e) for runs longer than 3 m.  Terminate
the bus with a 120 Ω resistor at each end for runs longer than ~10 m.

Power Supply
------------

Connect a **24 V DC** supply to the power terminals to power the ModBridge Pro B15.

Status LEDs
-----------

Three indicator LEDs — Config Mode, Internet and Modbus RX Activity — plus a
24 V no-internet alert output, are described in detail in
:ref:`leds_buttons`.

Control Buttons
---------------

Two push-buttons are described in detail in :ref:`leds_buttons`.  Both are
read only during the first 10 seconds after power-on.


Device Label
============

Each unit carries a printed label with the information needed to commission
it without opening the enclosure or powering it up first:

.. list-table::
   :widths: 30 70
   :header-rows: 1

   * - Field
     - Meaning
   * - MODEL
     - Hardware variant, e.g. ``B15``.
   * - ``ModBridgePro_XXXXXX``
     - The exact SSID of this unit's configuration access point.  Type it as
       printed — the suffix is derived from the MAC address in a way that
       will not match a MAC printed elsewhere character-for-character.
   * - QR code
     - Opens this documentation.

Keep the label legible.  It is the only place the AP name is written down,
and a unit whose SSID is unknown has to be found by scanning for it.
