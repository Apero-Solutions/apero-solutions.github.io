ModBridge Pro Documentation

← Back to the ModbridgePro product page

ModBridge Pro B15 is a professional-grade industrial IoT gateway that bridges Modbus devices (sensors, energy meters, PLCs) with modern cloud platforms such as MQTT brokers and Google Sheets, using an ESP32-S3 microcontroller.

Note

This documentation covers firmware v2.2.1. For variant-specific pages (future hardware revisions or product tiers), see Product Variants.
