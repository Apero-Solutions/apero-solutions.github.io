Security

ModBridge Pro B15 is designed with industrial deployment in mind. Multiple layers of security protect your configuration, credentials, and data in transit.

Web Interface Authentication

Access to the configuration interface is protected by a username and password. The default credentials are admin / admin.

Danger

Change the default credentials immediately on first login. Default credentials are publicly known; anyone on the same network can access the configuration page if the defaults are left in place.

To change credentials at any time, click the 🔒 Change Login button in the top-right corner of the configuration page.

Note

Changing your login password automatically re-secures all stored IoT credentials (MQTT passwords, Google Sheets keys) — you do not need to re-enter them after a password change.

Credential Storage

IoT secrets (MQTT password, Google Sheets private key) are never stored in plain text on the device. All credentials are encrypted before being saved and can only be decrypted by the device itself.

Network Security Recommendations

  1. Isolate on a dedicated network. Place ModBridge Pro on a separate IoT or OT network, isolated from office and user devices.

  2. Enable TLS for MQTT. Toggle the TLS/SSL option in the IoT Publishing tab to encrypt all data in transit between the device and your broker.

  3. Use a dedicated MQTT account. Create a dedicated MQTT user with publish-only permissions for this device. Do not use broker admin credentials.

  4. Keep firmware updated. Apply firmware updates promptly — see Over-the-Air Firmware Update.

  5. Factory Reset is protected by design. The Factory Reset button (IO0) is located inside the ModBridge Pro B15 enclosure and is not accessible from the outside, preventing accidental or unauthorised resets in the field.

  6. The configuration access point closes automatically. The Wi-Fi access point is only active during configuration. It closes as soon as the device reboots after saving settings and does not reopen unless the Internet Reset button is pressed.

Time Synchronisation

ModBridge Pro synchronises its clock automatically every hour. All published data timestamps use IST (UTC +5:30). Accurate timestamps are important for correlating IoT data with events in process historians or ERP systems.

If the internet is unavailable, the device continues to publish data but timestamps may drift. The green status LED going off is a quick indicator that time sync may also be affected.
