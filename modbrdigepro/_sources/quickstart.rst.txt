.. _quickstart:

===========
Quick Start
===========

Get ModBridge Pro up and running in under 10 minutes by following the steps
below.

Prerequisites
=============

* ModBridge Pro B15, powered via 24 V DC.
* A laptop with Wi-Fi or Ethernet connectivity to configure the ModBridge Pro B15.
* In case of Wi-Fi configuration, your network name and password.
* In case of Ethernet configuration, the static IP address settings or DHCP server on the network.
* Modbus device(s) connected to the RS-485 terminal (for RTU) or Ethernet
  (for TCP).
* MQTT broker credentials **or** a Google Sheets service account (for cloud
  publishing).


Step-by-Step Setup
==================

Step 1 — Power on the ModBridge Pro B15
----------------------------------------

Connect the 24 V DC supply to the ModBridge Pro B15.  The Config Mode LED blinks slowly
during startup — this is normal.

Step 2 — Connect to the configuration access point
---------------------------------------------------

On your phone or laptop, open the Wi-Fi settings and look for a network
named::

   ModBridgePro_XXXXXX

The last 6 characters are the unique identifier of your device derived from
its hardware address, so multiple ModBridge Pro units on the same site will
always have different network names. Connect to it — **no password is
required**.

.. note::

   The unique 6-character suffix is printed
   on the device label.

Step 3 — Open the configuration page
--------------------------------------

If connected through WiFi then navigate to::

   http://192.168.4.1

If connected through Ethernet then navigate to::
   
   http://192.168.5.1

Log in with the default credentials:

.. list-table::
   :widths: 30 70

   * - **Username**
     - ``admin``
.. list-table::
   :widths: 30 70

   * - **Password**
     - ``admin``

A pop-up will prompt you to change these immediately.  **Do so before
continuing.**

Step 4 — Configure internet connectivity
-----------------------------------------

On the *Internet Connection* tab:

1. Choose **Wi-Fi** or **Ethernet** as the internet source.
2. For Wi-Fi, click **Scan Networks** and select your network, then enter the
   password.
3. For Ethernet, choose **DHCP** (automatic) or enter a **Static IP**
   configuration.

Step 5 — Configure the Modbus protocol
----------------------------------------

On the *Protocol Settings* tab:

1. Select **Modbus RTU** (RS-485 serial) or **Modbus TCP** (Ethernet).
2. For RTU, set the baud rate, data bits, parity, and stop bits to match
   your devices.
3. For TCP, enter the Modbus server IP, port (default 502), and the static
   Ethernet IP to assign to the device.

Step 6 — Add Modbus slave devices and registers
-------------------------------------------------

On the *Modbus Devices* tab:

1. Click **Add Device**.
2. Enter the **Slave ID** (1–247) as configured on the Modbus device.
3. Add registers: for each register provide a name, address, data type, and
   byte-swap setting.
4. Repeat for up to 5 devices.

See :ref:`configuration` for a full explanation of register addressing and
data types.

Step 7 — Set up cloud publishing
----------------------------------

On the *IoT Publishing* tab:

1. Select **MQTT** or **Google Sheets** (or **Disabled** to skip).
2. Fill in the broker / spreadsheet credentials.
3. Set the **Update Interval** (1–900 seconds).
4. Click **Test Connection** to verify before saving.

See :ref:`iot` for full MQTT and Google Sheets configuration details.

Step 8 — Save and reboot
--------------------------

Click **Save Configuration** at the bottom of the page.  The device saves
all settings and reboots automatically.

After reboot:

* The **Internet LED** lights solid green when the internet is reachable.
* The **Modbus RX Activity LED** pulses briefly with each successful Modbus
  poll.

.. warning::

   The default credentials ``admin / admin`` are publicly known.  Change
   them during Step 3.  Anyone on the same network can access the
   configuration page if you leave the defaults in place.
